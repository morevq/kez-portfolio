# Портфолио аниматора

Работы автоматически подхватываются из трёх папок. HTML редактировать не нужно.

## Как добавить работы

1. Положите файлы в нужную папку:
   - `works/insomnia`
   - `works/personal`
   - `works/storyboards`
2. Назовите их по порядку: `01`, `02`, `03` и так далее.
3. Если нужен заголовок карточки, добавьте его после номера: `01-night-shift.mp4` → `Night Shift`.

Поддерживаются изображения `JPG`, `PNG`, `WEBP`, `GIF`, `AVIF`; видео `MP4`, `WEBM`; в `storyboards` также поддерживается `PDF`.

### Имена для текущего набора

`works/insomnia`:

- `01-film.mp4`
- `02-background-01.png` … `06-background-05.png`
- `07-postcard.png`

`works/storyboards`:

- `01-animatic-01.mp4` … `04-animatic-04.mp4`
- `05-sequence-01.png` … `07-sequence-03.png`

Видео и изображения автоматически показываются отдельными группами. Три PNG из Storyboards выводятся единой последовательностью в правильном порядке.

## Локальный просмотр

В этой папке выполните:

```bash
npm run dev
```

Откройте `http://127.0.0.1:4173`. Новые файлы появляются на странице автоматически примерно за 3 секунды.

## Обычная локальная сборка

Выполните:

```bash
npm run build
```

Команда пересканирует папки, обновит `gallery-data.json` и положит сайт вместе с работами в `dist`.

На опубликованном сайте после добавления файлов нужен новый деплой: сайт в интернете не может читать папку на вашем компьютере напрямую.

## Публикация: GitHub Pages

Сайт и все публичные работы хранятся в одном GitHub-репозитории. Workflow `.github/workflows/pages.yml` автоматически собирает и публикует `dist` после каждого push в ветку `main`.

### Первая публикация

1. Создайте публичный GitHub-репозиторий и загрузите в него эту папку.
2. Откройте **Settings → Pages**.
3. В поле **Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь завершения workflow **Publish portfolio**.

Сайт появится по адресу `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

### Как обновлять портфолио после запуска

1. Положите новые файлы в `works` и сохраните текущую схему имён.
2. Сделайте commit и push в `main`.
3. GitHub Actions автоматически пересоберёт и опубликует сайт.

Ссылки на работы получают версию из времени изменения файла, поэтому при замене PNG или MP4 с тем же именем браузер загрузит новую версию.

### Когда появится домен

Добавьте домен через **Settings → Pages → Custom domain**, затем внесите показанные GitHub DNS-записи у регистратора. GitHub автоматически выдаст HTTPS-сертификат.
